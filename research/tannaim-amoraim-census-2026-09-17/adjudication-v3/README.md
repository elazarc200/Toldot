# הכרעות זהות — סבב 3

זהו סבב הכרעות מתועד, לא סיום הבירור של כל הרשומות.

- 23 איחודים מבוססי מקורות בסבב 3; 23 מוספים בסבבים 4–5 (סה״כ 46 איחודים מתועדים).
- 27 רשומות עברו לבירור שהוכרע ונכנסו למאגר (23+4).
- הספירה הנוכחית: 814 — 213 תנאים ו-601 אמוראים.
- 3416 רשומות מועמדות נותרו לבירור. זה אינו מספר אנשים.

הוכרעו בין היתר: סומכוס, קרנא, אמימר, רבי זריקא, זעירי, אילפא, עיפא, ברוריה, אדמון, פלימו, מרימר, באלי, חולפנא, רב אחא בר רב, רבי שבתי, רב חגא, רבי חוצפית המתורגמן, רבי ישבב, אבא יוסי חליקופרי ואבא אלעזר בן דולעאי.

אשיאן: תפקידו כ״תנא דרבי אמי״ אינו שיוך לתקופת התנאים; תוקן הסיווג השגוי. רב הינק: הוכרע שמדובר באדם אחד, אך התקופה נותרה לא ידועה כפי שנאמר במקור עצמו.
